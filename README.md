# Polyform

A modern low-poly 3D modeler with UV editing and skeletal animation, in the spirit of MilkShape 3D. Built with Vite, React and plain three.js.

## How to run

```bash
npm install
npm run dev        # open the printed URL (http://localhost:5173)
npm run build      # type-check + production build
npm test           # unit tests
npm run test:e2e   # needs `npm run dev` in another terminal
```

## What "working" looks like

1. **Empty scene** → click **Character + walk** (or Create → Character). The app jumps to Animate; **Space** plays the walk cycle; **Ctrl+Z** returns to your previous scene.
2. **Model, UV, Paint, Rig, Animate, Export** workspace tabs. Switch freely in any order; each workspace keeps its own layout, tools and panels. There is no hint bar: the status bar shows a short hint for the active tool, and **?** / **F1** lists every shortcut. Both side panels have a **«/»** chevron that folds them to a slim icon strip (click an icon to open that tab, or double-click the splitter). **Ctrl+[** toggles the tool panel, **Ctrl+]** the side panel, and **Ctrl+\\** hides both for a full-viewport focus mode (also in View, with checkmarks). Each workspace remembers its own panel state; the slide takes ~120 ms and is off with *prefers-reduced-motion*. The sidebars default to 144 / 256 px, the viewport headers are thin, and Frame / All / Reset / Grid show only while the pointer is over a view.
3. Four viewports (Top, Perspective, Front, Side). Left-drag uses the active tool, right-drag orbits (3D) or pans (2D), the wheel zooms, the ⤢ header button (or Shift+Space) maximizes a view. **Ctrl+drag** box-selects with any tool (Ctrl+Shift adds, Ctrl+Alt removes, Ctrl+click toggles).
4. **Model:** primitives (drag-a-box or double-click), the header's **Object | Vertex | Edge | Face** switch: **1** object, **2 / 3 / 4** vertex / edge / face (Shift combines), **Tab** toggles between Object and the last edit mode, and in Rig / Animate **Joints** (**5**). In Object mode a click picks a whole object (orange outline), Shift+click toggles, Ctrl+drag box-selects objects, the gizmo and G / R / S move the object around its origin, Shift+D duplicates it as a new object, Delete removes it, and the Outliner follows. **G / R / S** modal grab / rotate / scale; **E** extrude, **Ctrl+R** loop cut, **K** knife, **I** inset, **Ctrl+B** bevel, **F** fill, **M** merge. Each drag is one undo step (**Ctrl+Z** / **Ctrl+Shift+Z**).
5. **UV:** Auto UV, seams, pack, pin, stitch; **Palette** snaps selected faces to a paint-colour swatch on a palette image. The UV editor works in image pixels:
   - **Layout:** the UV workspace gives the UV editor about two thirds of the width, with the 3D view as a preview beside it (drag the divider, saved; ◂ ▸ maximize either side, ⇄ swaps them). One slim toolbar: UV/3D sync, the image, **Image ▾**, **UV ▾** (the right-click operations), **View ▾** (checker, snapping, units) and the overlay. The tool buttons sit in the right sidebar's **UV Tools** tab: an accordion (one group open, remembered) of Unwrap, Transform, Arrange, Pixels and Seams & pins, each a small grid of icon buttons, plus a card with the selection's faces, islands and pixel size; X / Y / W / H / angle appear over the canvas only while something is selected. The tool rail is icons here (its own setting).
   - **New objects** on a material with an image get UVs in pixels at the project's texel density (a box gets the box cross; other shapes their flat faces, packed upright), placed in the first free space of the image.
   - **Selection** is UV-local by default (**Sync: UV**): picking a point on a seam takes only that island's copy. **Sync: 3D** picks the mesh point in every island.
   - **Snap** while dragging to the pixel grid (Off / pixel / ½ / ¼). Ctrl inverts snapping and Shift makes it 4× finer. Rotation snaps to 15° (1° with Shift), and scaling snaps to whole texels.
   - **Selection frame:** 8 scale handles (Shift keeps the aspect, Alt scales from the centre), a rotate handle, and a pivot you move with Alt-drag. Handles grow for pen and touch. G / R / S still give modal transforms.
   - **Numbers:** X / Y / W / H of the selection in pixels (top-left origin) or 0–1 units, ∠ rotation, and ⟲ / ⟳ 90°.
   - **Unwrap (Blender style):** **Unwrap** cuts the mesh along its seams and flattens every piece with a least-squares conformal solver. **Angle based** (the default) first makes the angles consistent, ABF-style; **Conformal** (LSCM) uses the 3D angles directly. Pinned UVs stay where they are. Options: method, island margin and **Live Unwrap** (also in UV ▾): with two or more pins on an island, dragging a pin re-solves the island as you move it. **Smart UV Project** splits the faces wherever they turn more than the angle limit, projects each piece flat and packs them. It has its own angle limit, island margin and area weight. **Follow Active Quads** (Project ▾) lays a quad strip out straight from the active quad, which is the last one you Shift+clicked. Steps are either *even* or follow the 3D lengths (*length average*). **Lightmap Pack** (Project ▾) gives every face its own island, flattened and packed with its own margin. In Arrange, **Avg scale** (Average Islands Scale) gives every island the same UV size per 3D area. The total UV area stays the same, and islands with pins are left alone. **Relax** (Minimize Stretch, in Arrange and UV ▾) moves the UV points so that every triangle gets back its 3D shape. Pinned points stay put. Unwraps and projections only change the selected faces (all faces when nothing is selected); the new islands keep their place and texel density, or move to free space when that would cover other UVs.
   - **Ops:** the common ones in the Transform / Arrange groups, all of them in **UV ▾** and the right-click menu. They include rotate CW / CCW / 180 (Shift+R, Shift+Alt+R), flip, maximize, merge (Alt+M), align, distribute, straighten, cycle corners, move to cursor (Alt+U) and copy / paste face UVs (Ctrl+C / Ctrl+V over the editor). **F** frames the selection; **Home** or the zoom readout shows everything.
   - **Texel density** (px per unit, File → Properties, default 16) drives Auto UV packing on an image, the **Density** button, **Auto px** (each flat face group laid out straight on whole pixels) and **Box cross** (Minecraft-style layout). **View** projects from the last hovered 3D view.
   - **Pack** uses MaxRects (shelf packing as the fallback; about 10–20 % more of the image filled). Sizes that are not a power of two are flagged in the UV hint and the New / Resize dialogs, and a layout that does not fit at the texel density names a power-of-two size that would hold it.
   - **Image ▾** (UV toolbar): **New…** blank (colour or transparent, 1–4096 px, power-of-two presets) or a **UV template** (faces coloured by facing, 1-px face outlines, 2-px island borders, optionally packed first) put on the selected faces (all faces for a template with none selected); **Resize…** scales pixels (nearest; UVs stay) or extends the canvas at a 9-grid anchor (UVs follow, the model looks the same); **Flip** / **Rotate 90°** turn the image and its UVs together. Each is one undo step.
   - **Overlays:** Stretch, Overlap, Texel density and **Unused pixels** (magenta: paint no face uses; **Clear unused** makes it transparent, one undo step). Right-click → **Shared UVs** marks faces that reuse texels on purpose; the Overlap check leaves them out (saved per face, older files load unchanged).
   - **Hover sync:** the face under the pointer in a 3D view is outlined in the UV editor, and the face under the pointer in the UV editor is outlined in 3D. **Alt+click** in the UV editor selects every face covering that texel (finds hidden overlaps); **Ctrl+Alt+click** selects their islands. Alt-drag on the pivot still moves it.
6. **Paint:** image / vertex colour / weight paint; swatches; first image stroke creates a texture. Pixel art (Paint tab): **Round / Square** brush, **Pixel perfect** (whole texels, hard, 1-px strokes drop their L-corners, in the UV editor and 3D), **Lock alpha** (transparent texels stay transparent), **Fill** scope (face, UV island, object, connected colour, all of a colour), and **Shift+click** draws a line from the last stamp (15° snapping, Ctrl+Shift any angle) in the UV editor and in 3D. The UV editor shows the brush outline at its true texel size; its **UVs** button hides the UV wireframe while painting.
7. **Rig:** Joint tool (**J**) places bones; Auto bind; up to 4 weights per vertex; weight paint; **Alt+X** X-mirror.
8. **Animate:** scrub the timeline, pose with **G / R**, **I** keys (or auto-key ●), per-key easing in the inspector, onion skin, IK for limbs. Multiple named clips.
9. **Export:** **Ctrl+E** downloads a `.glb` (mesh, materials/images, skins, all clips) that passes the Khronos glTF validator. Also `.obj` and Save/Open `.polyform.json`. Drop `.glb` / `.gltf` / `.obj` / `.ms3d` / images onto the window to import.

10. **Menu bar** (File, Edit, View, Select, Create, Help): click a title, hover to move between open menus, arrow keys / Enter / Esc, greyed items when unavailable, shortcuts on the right. File has New (**Alt+N**, since browsers keep Ctrl+N), Open, Save / Save As, Import and Export submenus, Properties… (scene name, author, notes, units, export scale, Y/Z-up, frame rate, default clip, with live stats; saved in the project and written into the glTF asset extras) and Exit. New, Open project and Exit offer to save unsaved changes first. Browsers only let a page close windows it opened itself, so if the tab stays open Exit clears to an empty scene and tells you to close the tab. There is no Open Recent: a web page can't reopen files from disk by itself.

In dev builds the store is exposed as `window.__polyform` for tests.
